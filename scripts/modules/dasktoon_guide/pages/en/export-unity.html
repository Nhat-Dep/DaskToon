Export to Unity

Engine Export writes the model, its materials, the shaders, the rig and the clips in a form Unity reads, with the anime look kept.

Running it

Choose File › Export › Engine Export…, set Engine to Unity 6 (URP) and pick a folder. In a Unity project folder it writes under Assets/DaskToon, which Unity imports at once; in any other folder it writes a <Name>_Unity folder to drag into Unity's Project window. The dialog shows which of the two it will do. In a DaskToon project that is linked to Unity, Export This Model in the Project menu uses that folder.

Options

Selected Objects Only exports the selection. Model is the FBX, or No Model for the materials and shaders alone. Include Animation adds the clips (see Clips). Merge the Character's Meshes makes one mesh with each material kept; the file you work on stays as it is. Export Materials and Shaders writes the materials; Bake Size and Bake Samples set the pictures made from node setups that cannot be copied.

In Unity

The project must use the Linear color space (the URP default). Set Unity's Directional Light and Ambient as the export's report says: the intensity is the Sun's strength divided by π. The report is also in the Text Editor, in the text DaskToon Engine Export Report. With a second character, choose the Unity project folder itself when exporting (or use a DaskToon project): dragging a second _Unity folder in makes Unity report a duplicate GUID for the Shaders folder (the materials still work), and the Scripts folder may be in a project only once, so delete the second one. Exporting again overwrites manual edits to these assets.
