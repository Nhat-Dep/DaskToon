Face Shading

Face shading replaces facial skin normals with an egg-shaped proxy so anime cel shadows curve smoothly without catching on eye sockets or cheekbones.

Setting Up Face Shading

Select the character mesh, open the Object Data Properties tab, and locate the Face Shading panel. Click Set Up Face Shading: DaskToon locates the head bone, fits an egg proxy to the face, and adds the DaskToon Face Shading modifier. If unrigged or no head bone is found, switch to Edit Mode, select the face skin vertices, and try again.

Adjusting Face Shading

In the Face Shading panel, Coverage is how much the egg's normals replace the face's own (1 fully, 0 not at all); Falloff softens the edge where the face meets the neck and ears. Keep Nose Shadow and Keep Chin Shadow retain true geometric normals around the nose and jawline so facial features remain defined. Facial shadows update live and follow the character when the head turns.

Selecting the Proxy

Click Select Proxy in the Face Shading panel to select the proxy Empty directly in the 3D viewport. You can translate, rotate, or scale the proxy to adjust the angle and curvature of shadow boundaries across the face. The proxy is parented to the head bone and moves seamlessly with character poses.

Refitting the Proxy

If you alter the face topology or rescale the head, click Fit Proxy in the Face Shading panel. DaskToon recalculates the proxy size and position to fit the updated face mesh snugly. All previously tuned slider values are preserved.

Removing Face Shading

To remove face shading from a mesh, click Remove Face Shading in the Face Shading panel. DaskToon removes the modifier, clears the DT_Face vertex group, and deletes the proxy Empty if no other mesh shares it.
