The Interface

DaskToon looks like Blender and has a few places of its own. Everything of DaskToon's can be found in the places below.

The File menu

New, Open and Save work on projects and models, not loose files (see Projects and Models). Exporting to a game is File › Export › Engine Export…, and the Project menu in File has the shortcuts to it.

The Guide tab

Press N in the 3D viewport and open the Guide tab. Model Check checks your character: Check Model lists what to fix, Fix puts one right, and the ? beside a problem opens the page about it. Step by Step lists the steps from a new model to the game and shows which you are at. Read the Guide opens these pages.

Where DaskToon's panels are

Face Shading is in Properties › Object Data of a mesh (see Face Shading). Illustration Finish is in Properties › Scene (see Illustration Finish). The anime shader's node is in the Shader Editor, and the DaskToon nodes are in Shift A › DaskToon Anime (see The Anime Shader and Other Anime Nodes). Start Painting, Use DaskToon Shader and Anime Unwrap are in the material slot menu, and Anime Unwrap also in the UV menu of the 3D viewport.

Vietnamese

Set the language in Edit › Preferences › Interface. The DaskToon names are translated; where Blender already has its own translation of a word, Blender's is shown, which is why a few names read differently from the buttons of this Guide's English pages. The Vietnamese pages write the names as the Vietnamese interface shows them.
