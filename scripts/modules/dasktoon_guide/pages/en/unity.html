9. Unity

The last step takes the character to Unity, ready to play.

Engine Export

Use File › Export › Engine Export…. Pick a folder inside your Unity project and it writes under Assets/DaskToon, which Unity imports when you switch to it; pick any other folder and it writes a <Name>_Unity folder to drag into Unity's Project window. It writes the model, its materials and shaders, the rig file and the animation clips. Once it has run, this step shows done.

The light in Unity

Set Unity's Directional Light as the export's report says: its intensity is the sun's strength divided by π.
