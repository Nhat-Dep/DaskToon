Expression Tools

Tools that make, fill, split, rename and test the expressions of a face, kept as shape keys. They are under Shape Keys in the mesh's Object Data.

Auto Expressions

This panel comes first under Shape Keys, and the same buttons are in Expressions in the Anime Rig panel. Auto Expressions works on every mesh of the character: it fills the empty shape keys, makes the eye expressions that are missing, and leaves shape keys that already move as they are. New shape keys start at 0, so the face does not change until you use them.

The list under the button shows each expression. A ticked one moves something: press it to see it on the whole character, with the others off. A greyed one has no shape yet. Back to Rest Face turns the expressions off; other shape keys, such as a slimmer waist, stay as you set them.

Redo Eye Expressions writes blink, joy and surprised again from the eyes found now, over what those shape keys hold. Use it on keys from an older version: Auto Expressions keeps them because they move. It asks before it overwrites anything.

A mesh modelled in half, with a Mirror modifier, closes both eyes together: one side cannot move alone, so that mesh gets no blink of one side.

Expression Sets

VRM 0.x Set and VRM 1.0 Set add the expression shape keys the mesh does not have yet, empty and ready to sculpt. Synthesize ARKit 52 from VRM builds the 52 ARKit face tracking shape keys from the VRM or VRoid ones, and Add ARKit 52 Placeholders adds them empty. Convert Naming renames shape keys from one standard to another (VRoid, VRM 0.x, VRM 1.0).

Fill and sculpt

The two steps of Auto Expressions, one at a time, in the Expression Tools panel.

Fill Empty Expressions builds empty expression shape keys from the others: e from a and i, the sides of a blink, the upper lip, the VRM names. Sculpt Eye Expressions makes blink, blink on each side, joy and surprised for eyes built from loose pieces in front of the face, and for the skin under them; the mesh needs a DaskToon rig.

Expression Tools

Split Left / Right splits a symmetric shape key into a left and a right one, blended across the middle of the mesh. Bake Expression to New Shape Key saves the current mix of shape key values as a new shape key. Remove Empty Shape Keys removes the shape keys that move no vertex.

Expression Preview

Pick an expression and press Test on Model to see it alone on the whole character; Clear Values turns the expressions off. Blink, Speech and Emotions play a test in a loop until Esc or right click.
