Expression Controllers

A controller drives several shape keys with one handle or a bank of sliders, so you key a whole expression at once. A HUD in the 3D viewport lets you drag it.

The HUD

In the Controllers panel, Open Viewport HUD shows the active controller in the 3D viewport: drag the handle or the sliders, press I to insert a keyframe and Esc to close it. Close Viewport HUD does the same from the panel. Reset Group puts the handle back in the middle and the sliders at 0, Reset All does it for every controller, and Insert Keyframe keys the handle and its shape keys.

Setting up

Auto Detect VRM / VRoid finds the shape keys of the character and adds controllers for them; VRM Emotions, AIUEO Visemes, Blink Sliders and Ears & Tail add one set each. The controller types are an AIUEO star, an emotion wheel and a slider bank.

Your own controllers

The + and − beside the list add and remove a controller. Give it a name and a type. Under it, the second list holds the shape keys it drives: each has a target point on the pad and a radius. Generate 3D Rig Board adds a board next to the mesh with a frame and an empty handle for each controller, as a start for a rig.
