Projects and Models

In DaskToon every file belongs to a project: a folder that holds your models, their textures and the link to your game. New, Open and Save all go through it.

The start screen

On start, the left column lists your projects (New Project…, Open Project… and the recent ones) and the right column lists the models of the chosen project, with New Model…. Click a model to open it. Continue as Draft closes the screen and lets you work on the open scene without a project.

A project

New Project… asks for a name and a place, and optionally a game project to link. The project is a folder with a dasktoon_project.json file, a Models folder for the models and a Textures folder. Textures that lie outside the project are copied into Textures when you save, so the project holds everything.

The Project menu in File shows the chosen project and the game it is linked to, and has Project Settings… (name, game engine and its folder; linking installs the shaders there), Export This Model, Reinstall Shaders and Open Project Folder. A project does not need a game project when you make it; link one later.

Models

New Model… asks for a name and where to start: a DaskToon scene (a Sun, a camera, the DaskToon Anime Engine and the Standard view transform), an empty scene, the scene that is open, or a copy of another model. Models are saved as Models/<name>.blend. Models in the File menu lists the models of the project.

Save saves in place. Save Model As… saves a new model of the project and switches to it, Save Copy… writes a copy and stays where you are, and Save Incremental writes a numbered copy beside the file.

Drafts

A scene that belongs to no project, such as a new scene or a file opened from outside, is a draft; the top bar says so. Saving a draft asks for the project and a name through Save to Project, and the original file is never overwritten. Save Copy… and Save Incremental are not available for drafts.
