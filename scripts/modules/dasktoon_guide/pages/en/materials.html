6. Materials

What the character is painted with, and how it reaches Unity.

UV map

Every mesh needs a UV map: textures sit on it, and the Unity export bakes with it. It is listed in the Object Data properties under UV Maps. Fix makes one with Smart UV Project.

DaskToon's shader

Every material a face uses needs DaskToon's anime shader: it gives the flat anime shading and the outline, and it is what DaskToon's Unity shader reads. New materials have it already; for imported ones use the material slots' menu › Use DaskToon Shader (or on All Selected). Fix does it for the character.

No unused materials

Remove material slots no face uses, or Unity gets empty materials. Fix removes them.
