1. New Model

Every DaskToon character starts the same way, so the tools that come later know what to expect.

Start a new model

Choose File › New Model… and pick the DaskToon Scene. It brings a sun, a camera looking at the front and the anime engine, so what you see while modelling is what the character will look like.

The Guide tab

Press N in the 3D view to show the sidebar, and open the Guide tab. Check Model looks at the selected character (or every visible mesh when nothing is selected) and lists, for each thing DaskToon needs: ✓ fine, ⚠ should be fixed, ✗ must be fixed. Many have a Fix button; ? opens the part of these pages about it. Step by Step opens the first step not done.

What “right” means

A model is right when DaskToon's automatic tools work on it with no fixing by hand: the auto rig, the bend fixes at the knees and elbows, the expressions, the shader and the export to Unity. Each check says which tool needs it.
